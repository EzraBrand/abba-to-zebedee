# Ideas for the project (brainstorm, 15-Oct-2026)

Not started. Ranked within each group by expected value for the effort.

## Making it more useful to scholars

1. **Every list item gets at least one exact source.** Most items now have a Bavli or Yerushalmi
   segment link. A citation for each item (with Bekiut / Sefaria links) makes the lists citable and
   checkable. The gazetteer passes already add one for every candidate.
2. **Manuscript readings of the names** (see below). Many names differ between Vilna and the
   manuscripts (סיקרא / סקרא, המדורי / המדודי). A short "MS readings" note for disputed items is
   something no printed reference work gives at this scale.
3. **Stable item IDs and a citation line** ("Brand, Abba to Zebedee, list X, item n, version date"), so that
   others can cite a single entry. Add a version number and change log to the site.
4. **Download the dataset** (all lists as one CSV / JSON with section, item, sources) and deposit it
   in Zenodo with a DOI, so that it can be cited and reused in digital-humanities work.
5. **Cross-links to standard reference works** per item: Hyman (*Toldot*), Margaliot, Ilan's *Lexicon*,
   Wikipedia / Wikisource (many notes already have these).

## Making it interesting to general readers

1. **Short essays, one per topic**, each built from one list: word plays on names (איכו, פישון הגמל,
   בלה), nicknames and epithets (שקוד = Shmuel, ורדימס), women named in the Talmud, named non-Jews
   (Antoninus, Adrakan who served Rav), names that are not father's names (Ben Bag Bag).
   These fit the Substack, and each post links back to the list.
2. **A searchable "who's who" page**: type a name (Hebrew or English), see its categories, sources
   and the passages. The site already has a name filter and an all-items page; add English forms
   (from the gazetteers) so that general readers can find names.
3. **"Name of the day"**: one item with its story, from the lists (e.g. Pishon the camel driver,
   measured "with a hasty measure").
4. **Visual entry points**: a map of toponymic surnames (Alma coordinates exist), a timeline of
   tannaim / amoraim by naming pattern. These are optional; the owner rated maps and statistics low.

## Bekiut

Yes, but as a link between the two, not by moving the paper into Bekiut:
- **In Bekiut, mark names in the text**: where a segment mentions an item of the lists, show a small
  marker or tooltip ("Patronymic Alone: בן סירא"), linking to the item on the survey site. The
  segment refs in the notes make this possible without new research.
- **A "Names" page in Bekiut**: one page per person or name with all Bavli segments (from the
  gazetteers and the Steinsaltz English), and the survey's categories for that name.
- **Keep the survey as its own site** for the prose and the scholarly apparatus; link both ways.
This makes Bekiut more useful to every reader (who is this person?) and brings readers to the survey.

## Manuscripts (AlHaTorah)

shas.alhatorah.org shows, per segment, a "Manuscripts and Printings" pane and textual notes
(שינויי נוסח), for example `https://shas.alhatorah.org/Full/Chulin/49b.10`.
- Use: for each list item with a Bavli ref, read the variant readings of that segment and record
  how the manuscripts spell the name (Munich 95, Vatican, Florence, the Genizah, the printings).
  Report: the items where the manuscripts disagree with Vilna, and the paper's spelling choices.
- First check AlHaTorah's Terms of Use and Downloads pages, and ask for permission before reading
  pages automatically. A pilot of 20–30 disputed items, read by hand in the browser, is fine either way.
- Alternatives with open terms: the Friedberg Hachi Garsinan variants (needs an account), the
  Sefaria manuscript images (some tractates), and the Lieberman Institute (Saul Lieberman) for
  Yerushalmi / Tosefta.
